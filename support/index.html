Getting started

  1. Try it before you commit an afternoon. Tap ⋯ at the top left, then Load sample inventory. Three realistic devices appear so you can see what a filled-in record looks like. ⋯ → Remove sample data takes them away again, cleanly.
  2. Scan your first device. Tap the scan button at the top right and hold the camera over the barcode on the equipment label — usually near the serial number, often on the back or underside.
  3. Check what came back, then add a location before you save. Location is what turns a list of products into an inventory you can actually walk.
  4. Photograph the label. This is the step people skip and later wish they hadn't. Printed labels fade; a photo taken today is still readable in five years.
  5. Make a backup as soon as you have more than a handful of devices, and again whenever you have added a batch. ⋯ → Back up & restore.

Working through a whole building? Scan a room at a time and set the location as you go, rather than scanning everything and sorting it out later. Rooms are how anyone searching for equipment actually thinks about it.

Scanning

The camera will not read the barcode

In rough order of how often it is the cause: not enough light, the label is curved around a cylinder, the camera is closer than it can focus, or the label is worn.

Try backing off to 15–20 cm and letting the camera settle before moving closer. For a curved label, come at it square to the centre of the barcode rather than at an angle. For a 2D square code (Data Matrix), fill more of the frame than feels necessary.

If it still will not read, use ⋯ → Enter identifier by hand and type the number printed under the barcode. That path is fully supported, not a consolation prize — the lookup and everything after it work identically.

Which barcode types are supported?

The scanner reads Data Matrix, QR, PDF417, Aztec, Code 128, Code 39, Code 93, Codabar, Interleaved 2-of-5, ITF-14, EAN-8, EAN-13, UPC-E and their variants — which covers what appears on medical and dental equipment in practice.

Of those, the ones carrying a UDI are usually a GS1 code (Data Matrix or Code 128, often starting (01)) or a HIBCC code (starting +). Both are parsed fully, including the production data packed inside them: serial number, lot, expiry and manufacturing date where the label includes them.

It says the device is already in my inventory

You have scanned another unit of the same product — five identical handpieces share one device identifier, because the identifier describes the product, not the individual item. Choose Add another unit and give it a label such as Op 3 or the serial number. That is exactly what the prompt is for.

The camera permission prompt never appeared, or I said no

Open the iOS Settings app → BiomedPortal → Camera. Manual entry works either way.

Product lookups

“Not in the FDA database” — did I do something wrong?

Almost certainly not. AccessGUDID covers devices whose labelers were required to submit a record, and the requirement phased in over several years. Capital equipment that predates it — an older autoclave, a delivery unit, a compressor — is frequently absent, and so are many non-US products.

The device is still saved. Type the make and model yourself and it becomes a full record: searchable, photographable, and backed up like any other.

The lookup failed or timed out

The lookup needs an internet connection and depends on a US government service that is occasionally down for maintenance. The scan is never lost when this happens — the device is saved with what you have, and you can run the lookup again later from the device's own screen.

The details that came back are wrong or incomplete

BiomedPortal shows the record exactly as the labeler submitted it to the FDA; it does not edit or fill gaps. Blank fields mean the labeler left them blank. Anything you type yourself — make, model, serial, location — is kept separately and is never overwritten by a lookup.

Corrections to the underlying record have to be made by the labeler, through the FDA's GUDID system.

Photos and manuals

My PDF imported but no facts were extracted

The usual cause is that the PDF is a scan of paper. It looks like text to you and is a picture to the phone, so there is nothing to read. The manual is still attached and still opens — only the automatic extraction is unavailable, and the device screen says so rather than pretending it found nothing.

Where you can, download the manufacturer's own PDF from their website rather than scanning a printed copy.

“That file is too large”

Single manuals are capped at 60 MB so that one enormous scan cannot fill the phone. Manufacturer PDFs are almost always well under this; scanned ones often are not. Recompress it, or attach only the service section.

How much space will this use?

Roughly: a label photo is around 1 MB, and a typical manufacturer manual 5–10 MB. A practice with 80 devices, a label photo for each and manuals for half comes to somewhere near 400 MB. The current total is shown on the Back up & restore screen.

If space is tight, leave manuals out of the backup file — they can be downloaded again from the manufacturer, and your own photos cannot.

Backup and restore

How do I move my inventory to a new phone?

On the old phone: ⋯ → Back up & restore, choose a passphrase, Create backup, then Save backup file and put it somewhere both phones can reach — Files, a drive, AirDrop.

On the new phone: install BiomedPortal, open ⋯ → Back up & restore → Restore from a backup file, pick the file and enter the passphrase.

Restoring only ever adds. It will not overwrite or delete anything already on the phone, so running it twice is harmless.

I have forgotten the backup passphrase

The file cannot be opened. This is not a policy we can make an exception to — the encryption key is derived from the passphrase and the passphrase is stored nowhere, so there is no key and no back door. If the phone still has the inventory, make a fresh backup with a passphrase you record properly.

Restore says the file is not a BiomedPortal backup

Either the wrong file was picked — a backup ends in .bmpx — or the file was altered in transit. Some mail and chat services rewrite attachments. Re-export and move the file through Files or AirDrop instead.

Can I open a backup file on a computer?

Not without writing something to decrypt it, and that is the intended trade-off — the file is encrypted precisely so that nobody can. What is inside, once decrypted, is a plain JSON inventory followed by the attachment files, so nothing about the format traps your data in this app permanently.

Your data

How do I delete everything?

⋯ → About & privacy → Delete all equipment data. Every record, photo, manual and extracted fact goes immediately. Deleting the app does the same thing. Neither touches a backup file you saved elsewhere — delete that yourself.

Do you have a copy of my inventory?

No. There is no server and no account. See the privacy policy for exactly what does and does not leave the device.
